## Глава 2. Проектирование гибридной системы управления задачами (22-25 стр.)

### 2.1 Архитектурное решение
- Двухуровневая архитектура (бот + мини-приложение)
- Взаимодействие компонентов
- Выбор технологического стека с обоснованием

### 2.2 Обоснование выбора технологий
- **Платформа:** ВКонтакте (юридические аргументы и обоснование пилотного внедрения для отдела)
- **Язык бэкенда:** Python + FastAPI (сравнение с Flask, Node.js, Go)
- **База данных:** PostgreSQL (обоснование выбора для высоконагруженных систем, отказ от SQLite)
- **Фронтенд:** React + VKUI (сравнительная таблица фреймворков)
- **Визуализация:** Matplotlib + ReportLab

### 2.3 Проектирование базы данных
- ER-диаграмма
- Описание таблиц и связей
- Индексация и оптимизация запросов

### 2.4 Проектирование API для мини-приложения
- Спецификация REST API
- Форматы запросов/ответов
- Аутентификация через VK Bridge

### 2.5 UX/UI проектирование мини-приложения
- Информационная архитектура
- Схема экранов и навигации
- Прототипы интерфейса (скриншоты макетов)

### 2.6 Ролевая модель системы
- Иерархия ролей (администратор, менеджер, сотрудник)

- Целевые показатели времени отклика

- Пороговые значения нагрузки

## Глава 3. Реализация гибридной системы (25-30 стр.)

### 3.1 Разработка бэкенда на Python (FastAPI)
- Структура проекта (роуты, сервисы, схемы)
- Интеграция базы данных PostgreSQL (через SQLAlchemy ORM)
- Асинхронная обработка сообщений через VK API
- Клавиатуры и инлайн-кнопки
- Система статусов задач

### 3.2 Разработка мини-приложения на React + VKUI
- Инициализация проекта через create-vk-mini-app
- Настройка маршрутизации (React Router)
- Реализация экранов:
  - Дашборд с метриками
  - Список задач (с фильтрацией)
  - Карточка задачи (просмотр/редактирование)
  - Создание задачи (форма с валидацией)
  - Статистика и графики
  - Управление сотрудниками (для админа)
- Интеграция с VK Bridge
- Адаптивная вёрстка под мобильные устройства

### 3.3 Интеграция компонентов системы и безопасность
- Запуск асинхронного REST API на FastAPI (автогенерация OpenAPI)
- Авторизация запросов и валидация подписи VK Sign
- Обработка CORS и защита эндпоинтов (JWT)
- Отправка уведомлений через бота

### 3.4 Реализация системы отчётности и визуализации
- Генерация Excel-отчётов (openpyxl) и PDF (ReportLab)
- Построение графиков (matplotlib)
- Вынос тяжелой генерации в фоновые задачи (BackgroundTasks)
- Кэширование отчётов для ускорения ответа API

### 3.5 Деплой и хостинг
- Размещение бэкенда (варианты: VPS, Yandex Cloud, Selectel)
- Деплой мини-приложения на хостинг VK
- Настройка HTTPS и домена
- Автоматизация развёртывания

### 3.6 Листинги ключевых модулей (в приложении)
- main.py (инициализация FastAPI и фоновых задач)
- bot.py (асинхронный хэндлер сообщений)
- database.py (схемы БД SQLAlchemy)
- App.jsx (главный компонент React)
